**Инструкция пользователя**

**Система учёта оборудования компьютерных классов. Версия 1.0. 13 ноября 2026 г.**

## **1\. Кому предназначена**

**Лаборант** ведёт учёт техники: добавляет, ищет, изменяет, удаляет записи, переводит технику в ремонт или на списание. **Преподаватель** проверяет оснащение кабинета перед занятием: какие компьютеры, мониторы, проекторы стоят в аудитории и в каком они состоянии.

Программа рассчитана на одного человека за одним компьютером. Специальных знаний программирования не требуется, достаточно уметь открыть терминал и ввести команду.

## **2\. Что нужно для работы**

**Компьютер** с ОС Windows 10 или 11, Linux (Ubuntu, Debian, Mint) или macOS. **Python 3.10 или новее.** Программа написана на Python и без него не запустится. **Ничего дополнительно устанавливать не нужно:** программа работает на стандартной библиотеке Python, ни базы данных, ни сторонних пакетов. **Для запуска тестов** (нужно только разработчику и проверяющему) установить pytest командой python \-m pip install \-r requirements.txt.

### **2.1. Как проверить, что Python установлен**

**Windows:**

1. 	  
   Нажмите Win \+ 	R, введите cmd, 	нажмите Enter. Откроется «Командная 	строка».  
2. 	  
   Введите:  
    	  
   python \--version  
3. 	  
   Нажмите Enter.  
4. 	  
   Если появилось Python 	3.10.x или выше, всё в порядке.  
5. 	  
   Если появилось Python 	was not found или python 	не является внутренней или внешней 	командой, Python не установлен или не 	добавлен в PATH. Перейдите к разделу 3.2.

**Linux или macOS:**

1. 	  
   Откройте терминал: Ctrl 	\+ Alt \+ T (Linux) или Cmd 	\+ Пробел → «Терминал» (macOS).  
2. 	  
   Введите:  
    	  
   python3 \--version  
3. 	  
   Нажмите Enter.  
4. 	  
   Если появилось Python 	3.10.x или выше, всё в порядке.  
5. 	  
   Если команда не найдена, установите 	Python (раздел 3.1).

**Важно для Linux и macOS:** в этих системах команда обычно называется python3, а не python. Если python \--version не сработал, попробуйте python3 \--version. Дальше в инструкции везде, где написано python, на Linux и macOS используйте python3.

Нажмите **«Создать»** и введите 	путь к Python, например:

1.

4. 	  
   Откроется терминал, в строке 	приглашения будет путь к папке проекта.

**Windows, способ 2:**

1. 	  
   Нажмите Win \+ 	R, введите cmd, 	Enter.  
2.

   cd C:\\Users\\ВашеИмя\\Documents\\inventory-project

   Нажмите Enter.

**Windows, способ 3:**

1. 	  
   Откройте папку проекта в «Проводнике».  
2.

**Linux:**

2.

## **5\. Что умеет каждая команда**

### **Пункт 1\. Показать всё оборудование**

**Что делает:** выводит таблицу всех записей в базе.

**Колонки таблицы:** **Инв. №** уникальный инвентарный номер (INV-0001). **Тип** ПК, монитор, принтер, проектор и т.д. **Наименование** модель, например Dell OptiPlex 3080. **Кабинет** номер аудитории (101). **Состояние** исправно, требует ремонта или списано. Подсвечено цветом: **зелёный** исправно, **жёлтый** требует ремонта, **красный** списано. **Поступило** дата поступления. **Ответственный** ФИО или должность.

**Внизу таблицы** строка «Всего записей: N».

**Если база пуста** сообщение «Список пуст.». Это нормально при первом запуске.

**Пошагово:**

1. 	  
   В меню введите 1 	→ Enter.  
2. 	  
   Изучите таблицу.  
3. 	  
   Нажмите Enter, чтобы вернуться в меню.

**Если цвета не отображаются** (старые версии Windows), это не ошибка, таблица всё равно читается.

### **Пункт 2\. Добавить оборудование**

**Что делает:** создаёт новую карточку техники. Номер присваивается автоматически.

**Пошагово:**

1. 	  
   В меню введите 2 	→ Enter.  
2. 	  
   Программа покажет: «Инвентарный 	номер будет присвоен автоматически: 	INV-0008». **Вводить номер не нужно.**  
3. 	  
   ▸ Тип (ПК / 	Монитор / Принтер …) \*: введите тип, 	например Монитор 	→ Enter. Пустой Enter **отмена добавления**, 	возврат в меню.  
4. 	  
   ▸ Наименование 	\*: введите модель, например LG 	24MP400 → Enter. Пустой Enter отмена.  
5. 	  
   ▸ Кабинет \*: 	введите номер кабинета, например 101 	→ Enter. Пустой Enter отмена.  
6. 	  
   ▸ Состояние 	\*: введите одно из: исправно, 	требует ремонта, 	списано → 	Enter. Если ошиблись, программа скажет 	«Нет такого состояния…» и попросит 	ввести снова. Пустой Enter отмена.  
7. 	  
   ▸ Дата 	поступления (необязательно): введите 	дату, например 01.09.2025, 	или нажмите Enter, чтобы пропустить.  
8. 	  
   ▸ Ответственное 	лицо (необязательно): введите ФИО, 	например Иванов 	И.И., или Enter, чтобы пропустить.  
9. 	  
   Программа покажет: «✔ Запись 	добавлена. Присвоен номер INV-0008».  
10. 	  
    Нажмите Enter, чтобы вернуться в меню.

**Важно:** **Обязательные поля:** тип, наименование, кабинет, состояние. Без них запись не создастся. **Необязательные поля:** дата и ответственный. Если пропустить, в карточке будет «неизвестно». **Номер никогда не выдаётся повторно**, даже после удаления последней записи. Если удалили INV-0008, следующая запись получит INV-0009. **Пустой ввод в обязательном поле** отменяет добавление целиком, ничего не сохранится.

### **Пункт 3\. Найти по инв. номеру**

**Что делает:** показывает карточку одной единицы техники по номеру.

**Пошагово:**

1. 	  
   В меню введите 3 	→ Enter.  
2. 	  
   ▸ Введите 	инв. номер: введите номер, например 	INV-0003 → Enter.  
3. 	  
   Программа покажет карточку: номер, 	тип, наименование, кабинет, состояние, 	дата, ответственный.  
4. 	  
   Нажмите Enter, чтобы вернуться в меню.

**Особенности:** **Регистр букв не важен:** inv-0003 и INV-0003 найдут одно и то же. **Лишние пробелы не мешают:** INV-0003 тоже сработает. **Если номера нет** сообщение «Не найдено.». **Пустой Enter** сообщение «Пустой ввод.» и возврат в меню, без падения.

### **Пункт 4\. Показать кабинет**

**Что делает:** выводит таблицу всей техники выбранного кабинета.

**Пошагово:**

1. 	  
   В меню введите 4 	→ Enter.  
2. 	  
   ▸ Введите 	номер кабинета: введите номер, 	например 101 	→ Enter.  
3. 	  
   Программа покажет таблицу только 	техники кабинета 101 (в том же виде, что 	пункт 1).  
4. 	  
   Нажмите Enter, чтобы вернуться в меню.

**Особенности:** **Если в кабинете ничего нет** сообщение «В кабинете 101 нет оборудования.». **Пустой Enter** «Пустой ввод.» и возврат в меню.

### **Пункт 5\. Изменить запись**

**Что делает:** меняет состояние и (или) кабинет существующей записи.

**Пошагово:**

1. 	  
   В меню введите 5 	→ Enter.  
2. 	  
   ▸ Инв. номер 	записи: введите номер, например 	INV-0003 → Enter.  
3. 	  
   Программа покажет карточку текущих 	данных.  
4. 	  
   ▸ Новое 	состояние (исправно / требует ремонта 	/ списано): введите новое состояние 	или нажмите Enter, чтобы не менять.  
5. 	  
   ▸ Новый 	кабинет: введите новый кабинет или 	Enter, чтобы не менять.  
6. 	  
   Программа покажет «✔ Запись 	обновлена» и карточку с новыми данными.  
7. 	  
   Нажмите Enter, чтобы вернуться в меню.

**Особенности:** **Можно изменить только одно поле:** например, только состояние, оставив кабинет пустым. **Оба поля пустые** сообщение «Ничего не изменено.», запись не тронута. **Недопустимое состояние** «Состояние должно быть одним из: исправно, требует ремонта, списано.» Изменение не применяется. **Неизвестный номер** «Не найдено.».

### **Пункт 6\. Удалить запись**

**Что делает:** удаляет карточку техники из базы **безвозвратно**.

**Пошагово:**

1. 	  
   В меню введите 6 	→ Enter.  
2. 	  
   ▸ Инв. номер 	записи: введите номер, например 	INV-0005 → Enter.  
3. 	  
   Программа покажет карточку того, 	что будет удалено.  
4. 	  
   ▸ Точно 	удалить? (да/нет): введите да 	→ Enter.  
5. 	  
   Программа покажет «✔ Запись 	удалена».  
6. 	  
   Нажмите Enter, чтобы вернуться в меню.

**Подтверждение удаления:** **Удаляют только ответы:** да, д, yes, y (в любом регистре). **Любой другой ответ, включая пустой Enter,** отменяет удаление, запись остаётся. **Неизвестный номер** «Не найдено.».

**Рекомендация:** обычно технику лучше **не удалять**, а переводить в состояние «списано» через пункт 5, история сохранится, и запись останется в базе для отчётности.

### **Пункт 7\. Фильтр по состоянию**

**Что делает:** показывает только технику с нужным состоянием и, при необходимости, в нужном кабинете. Удобно завхозу: сразу видно, что в ремонте или на списании.

**Пошагово:**

1. 	  
   В меню введите 7 	→ Enter.  
2. 	  
   ▸ Состояние 	(исправно / требует ремонта / списано): 	введите состояние, например требует 	ремонта → Enter. Недопустимое 	состояние → «Нет такого состояния, 	введите одно из списка выше.» Пустой 	Enter → «Пустой ввод.» и возврат в меню.  
3. 	  
   ▸ Кабинет 	(необязательно, Enter все): введите 	номер кабинета, например 101, 	или нажмите Enter, чтобы фильтровать 	только по состоянию.  
4. 	  
   Программа покажет таблицу подходящих 	записей.  
5. 	  
   Нажмите Enter, чтобы вернуться в меню.

**Примеры:** Состояние требует ремонта, кабинет пустой → **вся техника, которой нужен ремонт**, по всем кабинетам. Состояние исправно, кабинет 101 → **только исправная техника кабинета 101**. Состояние списано, кабинет 101 → если такой техники нет, сообщение «В кабинете 101 нет такой техники.».

### **Пункт 0\. Выход**

**Что делает:** завершает программу.

**Пошагово:**

1. 	  
   В меню введите 0 	→ Enter.  
2. 	  
   Программа покажет «До свидания\!» 	и закроется.

**Важно:** отдельной кнопки «Сохранить» **нет**, все изменения записываются в файл сразу после каждого действия. Выход через 0 ничего не теряет.

**Если закрыть окно терминала крестиком** программа завершится, но лучше выходить через 0, чтобы увидеть сообщение об успешном завершении.

## **6\. Где хранятся данные**

**Файл:** data/inventory.json в папке программы. **Формат:** JSON, обычный текстовый файл, его можно открыть блокнотом для просмотра (но **не редактируйте вручную**, легко испортить структуру). **Папка data** всё хранилище программы.

### **6.1. Как сделать резервную копию**

1. 	  
   Закройте программу (пункт 0).  
2. 	  
   Откройте папку проекта в «Проводнике» 	или файловом менеджере.  
3. 	  
   Скопируйте **папку data 	целиком** (не только inventory.json) 	на флешку, в облако или в другую папку.  
4. 	  
   Назовите копию с датой, например 	data-backup-2026-11-13.

### **6.2. Как восстановить из резервной копии**

1. 	  
   Закройте программу.  
2. 	  
   Скопируйте папку data 	из резервной копии **поверх** папки 	data в проекте.  
3. 	  
   Подтвердите замену файлов.  
4. 	  
   Запустите программу, данные 	восстановлены.

### **6.3. Как перенести базу на другой компьютер**

1. 	  
   Закройте программу на старом 	компьютере.  
2. 	  
   Скопируйте папку data 	на флешку.  
3. 	  
   На новом компьютере установите 	Python (раздел 3.1) и скопируйте папку 	проекта.  
4. 	  
   Скопируйте папку data 	с флешки **поверх** папки data 	в проекте на новом компьютере.  
5. 	  
   Запустите программу, записи на 	месте.

**Не запускайте программу одновременно на двух компьютерах с одной базой**, сохранится результат только последней записи, данные одного из пользователей потеряются (см. раздел 8).

## **8\. Известные ограничения версии 1.0**

**Один пользователь за раз.** Программу нельзя запускать одновременно на двух компьютерах с одной и той же базой: сохранится результат последней записи, данные другого пользователя потеряются. **Нет пароля.** Любой, у кого есть доступ к компьютеру, может изменить базу. Программа предназначена для локального использования на одном рабочем месте. **Только консоль.** Интерфейса с кнопками нет, работа ведётся в терминале. **Формат даты не проверяется.** Дату поступления можно ввести любой строкой, программа не проверяет, что это действительно дата. **Нет поиска по фрагменту наименования.** Есть поиск по инвентарному номеру (пункт 3), по кабинету (пункт 4\) и фильтр по состоянию (пункт 7). Найти технику по части названия, например «Dell», нельзя. **Резервные копии .corrupt-… не удаляются автоматически.** При частых сбоях файлы копятся в папке data, их нужно чистить вручную. **Печать отчётов не поддерживается.** Список техники можно только посмотреть на экране, выгрузить в Excel или на печать нельзя.

## **9\. Запуск тестов (для проверяющего)**

1. 	  
   Откройте терминал в папке проекта 	(раздел 3.4).  
2. 	  
   Установите зависимости:  
    	  
   python \-m pip install \-r requirements.txt  
    	На Linux и macOS:  
    	  
   python3 \-m pip install \-r requirements.txt  
3. 	  
   Запустите тесты:  
    	  
   python \-m pytest tests \-q  
    	На Linux и macOS:  
    	  
   python3 \-m pytest tests \-q  
4. 	  
   **Ожидаемый результат:** все тесты 	пройдены, ни одного проваленного. В 	конце строка вида 150 	passed.

**Если pytest не найден:**

python \-m pip install pytest

затем повторите запуск.

**Если тесты падают** приложите вывод терминала и файл data/inventory.json к сообщению об ошибке (раздел 10).

## **10\. Как сообщить об ошибке**

Сообщите разработчику три вещи:

1. 	  
   **Что вы делали** какой пункт меню 	выбрали и что вводили (последовательно).  
2. 	  
   **Что увидели** точный текст 	сообщения или описание поведения.  
3. 	  
   **Что ожидали увидеть** как должно 	было работать по инструкции.

**Если экран пустой или программа завершилась аварийно** приложите: файл data/inventory.json; папку data целиком (включая файлы .corrupt-…, если есть); скриншот терминала с ошибкой.

**Пример хорошего сообщения:**

Пункт 5, ввёл INV-0003, новое состояние списано, кабинет оставил пустым. Ожидал «Запись обновлена», увидел «Не удалось сохранить данные: Permission denied». Файл data/inventory.json прилагаю.

**Пример плохого сообщения:** «Не работает», по нему невозможно найти причину.
