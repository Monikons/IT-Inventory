1. ## **Поля карточки (уточнено)**

| Поле | Обязательное | Правило |
| :---- | :---- | :---- |
| inv\_number | Да | Уникальный, формат INV-XXXX |
| equipment\_type | Да | Из списка: ПК, монитор, принтер, сканер, проектор, МФУ, клавиатура, мышь, ИБП, другое |
| name | Да | Непустой текст |
| room | Да | Непустой номер/код кабинета |
| status | Да | Строго: исправно, требует ремонта, списано (регистр важен) |
| date\_added | Нет | ДД.ММ.ГГГГ |
| responsible | Нет | ФИО/должность |

   2. ## **Критерии приёмки US-2**

* **AC-1.** Все 5 обязательных полей заполнены → запись создаётся и сохраняется.

* **AC-2.** Пустое обязательное поле → понятная ошибка, запись не создаётся, программа не падает.

* **AC-3.** Дубликат инв. номера → отказ с сообщением.

* **AC-4.** Недопустимое состояние → отказ со списком допустимых значений.

* **AC-5.** Пустые необязательные поля → запись создаётся.

* **AC-6.** После добавления запись сразу видна в списке и сохранена в JSON.

* **AC-7.** Некорректный ввод → возврат в меню, без аварийного завершения.

## **Примеры для проверки**

**Корректные:** C-1 INV-1001 / ПК / Dell OptiPlex 7090 / 101 / исправно; C-2 INV-1002 / Монитор / LG 24MP400 / 310 / требует ремонта.

**Ошибочные:** E-1 пустой inv\_number; E-2 пустой equipment\_type; E-3 name из пробелов; E-4 пустой room; E-5 status=«работает»; E-6 дубликат INV-1001; E-7 status=«Исправно» (заглавная).
