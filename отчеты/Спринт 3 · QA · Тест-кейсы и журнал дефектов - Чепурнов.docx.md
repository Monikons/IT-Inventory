**Повторная проверка.** Когда LD исправит дефект, нужно запустить python \-m pytest tests \-rxX. Тест с пометкой xfail, который стал XPASS, значит, дефект устранён. Тогда убираем декоратор @pytest.mark.xfail у этого теста и меняем статус дефекта на «Исправлен, проверен».
