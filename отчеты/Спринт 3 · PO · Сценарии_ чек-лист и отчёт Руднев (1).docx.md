## **Правила подтверждения удаления и решения PO**

Удаление без явного «да» не выполняется никогда. Правила:

1. Перед удалением программа показывает карточку записи, чтобы пользователь видел, что именно удаляется.  
2. Затем задаётся вопрос «Точно удалить? (да/нет)».  
3. Удаление выполняют только ответы «да», «д», «yes», «y» (в любом регистре).  
4. Любой другой ответ, включая пустой, отменяет удаление: запись остаётся, выводится «Удаление отменено».  
5. Если номер не найден, подтверждение не запрашивается, показывается «Не найдено».

| :---- | :---- | :---- |

| DEF-02 — состояние с заглавной буквы при изменении | Требование: изменение ведёт себя так же, как добавление. Исправить в начале спринта 4 (перенесено) | Разное поведение одного и того же поля запутывает |
| DEF-03, DEF-04 — ошибки только при вызове из кода | Не блокируют приёмку; исправить по возможности | В меню пользователь их не увидит |
| DEF-05 — падение при повреждённой записи в файле | Требование: программа не завершается аварийно. Реализовать в спринте 4 вместе с хранением данных | Связано с US-7: повреждённый файл не должен теряться молча |
