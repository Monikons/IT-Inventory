# Инструкция пользователя

Система учёта оборудования компьютерных классов.
Версия 1.0 · 13 ноября 2026 г.

## 1. Кому предназначена

* **Лаборант** — ведёт учёт техники: добавляет, ищет, изменяет, удаляет записи.
* **Преподаватель** — проверяет оснащение кабинета перед занятием.

## 2. Что нужно для работы

* Компьютер с ОС Windows, Linux или macOS.
* **Python 3.10 или новее**. Проверить версию: открыть «Командную строку»
  (Windows) или терминал и выполнить `python --version`.
* Ничего дополнительно устанавливать **не нужно**: программа работает
  на стандартной библиотеке Python.
* Для запуска тестов (нужно только разработчику и проверяющему) —
  установить pytest: `python -m pip install -r requirements.txt`.

## 3. Установка

1. Скопировать папку проекта на компьютер.
2. Открыть терминал в этой папке (в Windows: зажать Shift, щёлкнуть
   правой кнопкой по пустому месту папки, выбрать «Открыть окно PowerShell здесь»).
3. Запустить программу:

```bash
python main.py
```

Если появляется ошибка «Python was not found», значит Python
не установлен или не добавлен в PATH. Нужно установить его
с сайта python.org и при установке отметить галочку «Add Python to PATH».

## 4. Как выглядит экран

После запуска видно рамку с названием «УЧЁТ ОБОРУДОВАНИЯ · КОЛЛЕДЖ»,
под ней — путь к файлу данных и количество записей, и главное меню:

```
1  Показать всё оборудование
2  Добавить оборудование
3  Найти по инв. номеру
4  Показать кабинет
5  Изменить запись
6  Удалить запись
7  Фильтр по состоянию
0  Выход
```

Для выбора пункта введите цифру и нажмите Enter. После каждого действия
нужно нажать Enter, чтобы вернуться в меню.

## 5. Что умеет каждая команда

### Пункт 1 — Показать всё оборудование

Выводит таблицу всех записей: инвентарный номер, тип, наименование,
кабинет, состояние, дата поступления, ответственный. Состояние
подсвечено цветом: зелёный — исправно, жёлтый — требует ремонта,
красный — списано.

### Пункт 2 — Добавить оборудование

1. Программа показывает номер, который будет присвоен (например, `INV-0008`).
   Вводить номер не нужно.
2. Заполните обязательные поля: **тип, наименование, кабинет, состояние**.
3. Дата поступления и ответственный — необязательные поля.
   Если их пропустить, в карточке будет «неизвестно».
4. Пустой ввод в обязательном поле отменяет добавление.
5. Номер никогда не выдаётся повторно, даже после удаления последней записи.

### Пункт 3 — Найти по инв. номеру

Введите номер, например `INV-0003`. Регистр букв не важен — `inv-0003`
найдётся тоже. Показывается карточка: кабинет, состояние, ответственный.
Если номера нет — сообщение «Не найдено».

### Пункт 4 — Показать кабинет

Введите номер кабинета, например `101`. Будут показаны все единицы
техники этого кабинета. Если в кабинете ничего нет — сообщение
«В кабинете 101 нет оборудования».

### Пункт 5 — Изменить запись

1. Введите инвентарный номер записи.
2. Программа покажет карточку текущих данных.
3. Введите новое состояние (исправно / требует ремонта / списано)
   и/или новый кабинет. Поле, которое не нужно менять, оставьте пустым.
4. Если оба поля пустые — сообщение «Ничего не изменено».

### Пункт 6 — Удалить запись

1. Введите номер. Программа покажет карточку того, что удаляется.
2. Ответьте `да`. Удаляют только ответы «да», «д», «yes», «y».
3. Любой другой ответ, включая пустой, отменяет удаление.

**Рекомендация.** Обычно технику лучше не удалять, а переводить
в состояние «списано» — история сохранится.

### Пункт 7 — Фильтр по состоянию

1. Введите состояние: `исправно`, `требует ремонта` или `списано`.
2. Кабинет можно не указывать — тогда фильтр только по состоянию.
   Если нужен конкретный кабинет, введите его номер.
3. Показывается таблица только подходящих записей.

Пример: состояние «требует ремонта», кабинет пустой — список всей
техники, которой нужен ремонт.

### Пункт 0 — Выход

Завершает программу. Отдельная кнопка «Сохранить» не нужна:
все изменения уже записаны в файл.

## 6. Где хранятся данные

Файл `data/inventory.json` в папке программы. Его можно скопировать
на флешку или в облако как резервную копию — скопируйте папку `data`
целиком.

Чтобы перенести базу на другой компьютер, скопируйте папку `data`
поверх имеющейся в папке программы.

## 7. Если что-то пошло не так

| Сообщение | Что это значит | Что делать |
|-----------|----------------|------------|
| «Файл данных ещё не создан — программа начнёт с пустого списка» | Первый запуск, база пустая | Всё в порядке, добавьте первую запись |
| «Файл данных пуст» | Файл есть, но в нём ничего не записано | Добавьте записи заново |
| «Файл данных повреждён: … Исходный файл сохранён как «inventory.json.corrupt-…»» | Файл испорчен | Не удаляйте копию `.corrupt-…`. Обратитесь к разработчику, чтобы восстановить записи |
| «Не удалось сохранить данные: …» | Нет прав на запись или занят файл | Проверьте, что файл не открыт в Excel; закройте его и повторите действие |
| «Не найдено» | Нет записи с таким номером | Проверьте номер по пункту 1 |
| «Пустой ввод» | Ничего не введено | Вернитесь в меню и повторите |
| «Нет такого состояния» | Опечатка в состоянии | Введите одно из: исправно / требует ремонта / списано |

## 8. Известные ограничения версии 1.0

1. **Один пользователь за раз.** Программу нельзя запускать одновременно
   на двух компьютерах с одной и той же базой: сохранится результат
   последней записи.
2. **Нет пароля.** Любой, у кого есть доступ к компьютеру, может
   изменить базу. Программа предназначена для локального использования.
3. **Только консоль.** Интерфейса с кнопками нет, работа ведётся
   в терминале.
4. **Формат даты не проверяется.** Дату поступления можно ввести
   любой строкой.
5. **Фильтр по состоянию и кабинету**, отдельного поиска по фрагменту
   наименования нет.
6. **Резервные копии** `.corrupt-…` не удаляются автоматически —
   при частых сбоях их нужно чистить вручную в папке `data`.
7. **Печать отчётов** не поддерживается.

## 9. Запуск тестов (для проверяющего)

```bash
python -m pip install -r requirements.txt
python -m pytest tests -q
```

Ожидаемый результат: все тесты пройдены, ни одного проваленного.

## 10. Как сообщить об ошибке

Сообщите разработчику:

1. что вы делали (какой пункт меню и что вводили);
2. что увидели (текст сообщения);
3. что ожидали увидеть.

Если пустой экран или программа завершилась — приложите файл
`data/inventory.json` и папку `data` целиком.
