# User Stories и критерии приёмки

| ID | Приоритет | Спринт | User Story | Критерии приёмки |
|----|-----------|--------|------------|------------------| 
| US-1 | Must | 1 | Как лаборант, я хочу видеть список всего оборудования, чтобы понимать, что у нас есть. | 1) Пункт меню «Показать оборудование» выводит не менее 5 записей. 2) У каждой видны номер, тип, наименование, кабинет, состояние. 3) При пустом списке показано «Список пуст». |
| US-2 | Must | 2 | Как лаборант, я хочу добавлять новое оборудование, чтобы список был актуальным. | 1) При вводе всех 5 обязательных полей запись появляется в списке. 2) Пустое поле — понятная ошибка, запись не создаётся. 3) Уже существующий инвентарный номер не принимается. 4) Программа не завершается аварийно. |
| US-3 | Must | 3 | Как лаборант, я хочу находить компьютер по инвентарному номеру, чтобы быстро узнать, в каком кабинете он находится. | 1) По существующему номеру показывается карточка. 2) По неизвестному — сообщение «Не найдено». 3) Пустой ввод не приводит к аварии. |
| US-4 | Should | 3 | Как преподаватель, я хочу видеть всё оборудование кабинета, чтобы проверить его наличие перед занятием. | 1) По номеру кабинета выводятся все его записи. 2) Если записей нет — сообщение «В кабинете нет оборудования». 3) Пустой ввод обрабатывается без аварии. |
| US-5 | Must | 3 | Как лаборант, я хочу менять состояние или кабинет записи, чтобы данные отражали ремонт и перенос техники. | 1) Допустимы только состояния «исправно», «требует ремонта», «списано». 2) Неизвестный номер — «Не найдено». 3) Новое значение видно в списке сразу после изменения. |
| US-6 | Must | 3 | Как лаборант, я хочу удалять ошибочные записи, чтобы список не засорялся. | 1) Перед удалением программа просит подтверждение. 2) При отмене запись остаётся. 3) Неизвестный номер — «Не найдено», без аварии. |
| US-7 | Must | 4 | Как лаборант, я хочу, чтобы данные сохранялись после закрытия программы, чтобы не вводить их заново. | 1) После перезапуска записи на месте. 2) Если файла нет — старт с пустым списком без сбоя. 3) Повреждённый JSON даёт сообщение и не стирает данные молча. |
